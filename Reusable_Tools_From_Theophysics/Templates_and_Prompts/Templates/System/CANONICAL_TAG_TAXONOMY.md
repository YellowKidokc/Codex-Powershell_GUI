## USAGE RULES

1. **Primary tags only.** Use the tag column, not aliases, in all systems.
   Aliases exist for search/matching — the canonical tag is what gets stored.

2. **Multi-tag.** A document can have multiple tags. A paragraph about
   Law I that cites PEAR data gets: `law-01`, `pair-I`, `var-G`, `var-R`,
   `evidence`, `data-pear`, `physics`, `theology`.

3. **Callouts use content types.** When generating inline callouts,
   use content type tags: `axiom`, `law`, `evidence`, `hypothesis`,
   `prediction`, `falsification`, `convergence`, `equation`, `timewall`,
   `isomorphism`.

4. **Knowledge graph uses all.** Node types = content types.
   Edge types = structural types. Properties = domain + variable + status.

5. **Semantic AI plugin maps to this.** The plugin classifiers
   (Axiom, Claim, EvidenceBundle, LawMapping, MasterEquation,
   Falsification, ScripturePhysics, Prosecution, TimeWall, Convergence)
   each output tags from this list.

6. **YAML copilot maps to this.** Every YAML block uses these tags.

7. **ai.faiththruphysics.com maps to this.** The MCP server query
   results return these tags as structured metadata.
