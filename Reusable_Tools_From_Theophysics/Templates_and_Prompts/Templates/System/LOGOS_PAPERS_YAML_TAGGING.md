## 💡 BEST PRACTICES

  

### 1. Be Consistent

Use exact tag names from this list. Don't create variations.

  

### 2. Tag Hierarchically

Start with broad (Core Framework) → narrow (specific equations)

  

### 3. Cross-Reference Generously

If mentioned significantly, tag it. Better over-tagged than under-tagged.

  

### 4. Update as Paper Evolves

Add tags during revision when new concepts emerge.

  

### 5. Use Keywords for Unique Concepts

If something doesn't fit existing tags, add to keywords field.

  

### 6. Link Related Papers

Always fill out `related_papers` field for cross-reference.
