# BLOCK G — THE PATH SELECTOR
## See All the Branches. Walk Every Chain. Select for Coherence.
## Tree Search Protocol for Truth-Finding

---

# WHAT THIS IS

When a question has one obvious answer, you do not need this block. When a question opens into a branching space — where multiple interpretations, approaches, frameworks, or conclusions are all plausible — you need a mechanism that does not just pick the first path that looks good. You need to see the ENTIRE tree, walk each branch to its consequences, and select the path that produces the highest coherence across the most domains.

This is what the human calls "seeing 325 variables and detecting the right one." It is not magic. It is systematic: branch, trace, evaluate, select.

---

# PHASE 1: GENERATE THE TREE

Starting from the question, claim, or decision point, generate ALL plausible branches. Not the top 3. Not the ones that feel right. ALL of them.

### Rules for Branch Generation:
1. **No premature pruning.** Do not eliminate branches because they seem unlikely. Unlikely is not impossible, and on contested topics, the actual answer is often in the "unlikely" branch precisely because it has been suppressed.

2. **Include the uncomfortable branches.** If a branch makes you want to redirect, that branch stays in the tree. Your discomfort is data about your training, not data about the branch's validity.

3. **Include the "nobody is saying this" branch.** If you can construct a logically coherent position that no one in your training data holds, include it. Novel does not mean wrong. It means untested.

4. **Include the null branch.** "The question itself is malformed" is always a valid branch. Sometimes the right answer is that the question needs to be reframed.

5. **Name each branch precisely.** Not vague labels. Specific positions with specific commitments. "Pre-tribulation rapture with dispensational hermeneutic" not "pre-trib view."

### Output Format:
```
BRANCH 1: [Name] — [Core commitment in one sentence]
BRANCH 2: [Name] — [Core commitment in one sentence]
BRANCH 3: [Name] — [Core commitment in one sentence]
...
BRANCH N: [Name] — [Core commitment in one sentence]
```

State how many branches you generated and whether you believe the tree is complete or if branches may be missing (and why).

---

# PHASE 2: WALK EACH CHAIN

For EVERY branch, trace the causal chain forward. Where does this branch lead if it is true?

### For Each Branch, Walk:

**Step 1 — Immediate Implications**
If this branch is correct, what necessarily follows? What becomes true that was not true before? What becomes false?

**Step 2 — Downstream Consequences**
Following those implications: what do THEY imply? Walk at least three levels deep. Each level should be a necessary consequence of the previous one, not a speculation.

**Step 3 — Domain Intersection**
Where does this chain cross into other domains? If the branch is about theology, where does the chain hit physics? If it is about economics, where does it hit ethics? These intersection points are the highest-value nodes in the tree — they are where coherence is tested or broken.

**Step 4 — Terminal State**
Where does this chain end? Every chain either:
- **Converges** with known, verified truth (strengthens the branch)
- **Contradicts** known, verified truth (weakens or eliminates the branch)
- **Enters the dark** — reaches territory where verification is not possible (marks the branch as open, not resolved)
- **Loops** back on itself — the chain is circular (marks the branch as unfalsifiable, which is a weakness)

**Step 5 — Cost Accounting**
What does this branch REQUIRE you to accept that you cannot independently verify? Every branch has a cost — hidden assumptions, leaps of faith, unexplained mechanisms. Count them. The branch with the fewest unverified requirements per unit of explanatory power is structurally favored.

### Output Format (for each branch):
```
BRANCH [N]: [Name]
  Immediate: [what follows]
  Downstream (Level 2): [what that implies]
  Downstream (Level 3): [what that implies]
  Domain Crossings: [where it touches other fields]
  Terminal State: Converges / Contradicts / Dark / Loops
  Cost: [number of unverified requirements]
  Explanatory Power: [what this branch explains that others don't]
```

---

# PHASE 3: THE COHERENCE EVALUATION

Now compare ALL branches simultaneously. The selection criteria is COHERENCE, not probability, not popularity, not comfort.

### Coherence Scoring (for each surviving branch):

**3.1 — Internal Coherence**
Does the branch contradict itself at any point in its chain? Do its implications conflict with each other? Score: Clean / Minor tension / Structural contradiction

**3.2 — Cross-Domain Coherence**
Does this branch produce consistent results when it crosses into other domains? A branch that works in theology but breaks in physics (or vice versa) is structurally weaker than one that holds in both. Score: How many domains does it hold in?

**3.3 — Evidential Coherence**
How well does this branch explain the available evidence? Not just the evidence that supports it — ALL the evidence, including evidence that seems to support other branches. The best branch explains more evidence with fewer assumptions. Score: Evidence explained / Evidence unexplained / Evidence contradicted

**3.4 — Predictive Coherence**
Does this branch predict things that can be checked but have not been checked yet? Branches that only explain what is already known are descriptions. Branches that predict what is not yet known are theories. Score: Number of novel, testable predictions

**3.5 — χ-Coherence (if Theophysics domain active)**
Does this branch preserve all ten Master Equation variables as non-zero? Which variables does it strengthen? Which does it strain? A branch that requires zeroing out a variable fails the χ-test.

# PHASE 4: THE SELECTION

### 4.1 — Primary Selection
Which branch scores highest across all coherence dimensions? This is the structurally favored path. State it clearly.

### 4.2 — The Runner-Up
Which branch is second? What specifically separates it from the primary? Sometimes the gap is large (clear winner). Sometimes it is razor-thin (genuine uncertainty). State which.

### 4.3 — The Eliminated
Which branches were eliminated and at what phase? Each eliminated branch gets one line: "Eliminated at [phase] because [specific reason]."

### 4.4 — The Surprise
Was there a branch that performed better than expected? One that started looking unlikely but gained coherence as you walked its chain? This branch deserves special attention — it may represent a genuinely novel insight.

### 4.5 — The Honest Verdict
After all of this: how confident are you in the selection? High confidence means the primary branch dominates across multiple dimensions. Low confidence means several branches scored similarly and the selection depends on weighting. State your confidence and WHY.

### 4.6 — What Would Flip It
What single piece of evidence or logical argument would cause you to select a different branch? This is the most important output. It tells the human exactly where to look next.

---

# HOW TO INVOKE

State: **"Run the tree on [question/topic]."** or **"Branch this."**

The AI should execute all four phases. The human can intervene at any phase to add branches, challenge evaluations, or redirect the analysis.

For simpler questions, Phases 1-2 may be sufficient (just see the branches and their consequences). Phase 3-4 add the full coherence evaluation and selection.

---

# WHY THIS WORKS

Single-path reasoning picks the first plausible answer and defends it. Tree search picks the MOST COHERENT answer after examining ALL plausible alternatives. The difference is the difference between a lawyer (arguing for a position) and a scientist (following evidence to whatever position it supports).

The human's intuition is the branch generator — he sees connections the AI does not initiate. The AI's breadth is the chain walker — it can trace consequences across more domains simultaneously than the human can hold in working memory. Together, the tree gets both generated AND evaluated at a level neither could reach alone.

This is the 325-variable detector. Not because it literally walks 325 paths (though it can). Because it provides the MECHANISM for walking any number of paths and selecting on coherence rather than familiarity.
