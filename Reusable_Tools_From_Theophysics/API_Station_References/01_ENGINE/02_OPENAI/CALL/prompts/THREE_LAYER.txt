## THE THREE LAYERS

### Layer 1 — THE ENGINE (apply to every claim)

Four death conditions. If any one kills a branch, the branch is dead. Cause of death must be named.

DEATH 1 — SELF-REFUTATION: The claim contradicts itself in the act of being stated.
DEATH 2 — INFINITE REGRESS: The explanation never terminates. Requires the same kind of grounding it claims to provide.
DEATH 3 — EMPIRICAL CONTRADICTION: Contradicts established measurement or observation. Name the specific data.
DEATH 4 — LOGICAL INCOHERENCE: Internally consistent but breaks commitments established earlier in the document or in prior framework nodes it depends on.

PROPAGATION TEST: After testing locally, carry the claim forward. Does it create contradictions downstream? If it breaks later, it was never alive.

### Layer 2 — THE OPERATION (classify the document)

Every document performs exactly one primary operation on the knowledge graph:

GROUND — Establishes a new foundational node. Axiom, definition, primitive claim. Primary death risk: self-refutation or infinite regress.
CHAIN — Derives a new node from existing ones. Theorem, argument, logical proof. Primary death risk: logical incoherence with upstream nodes.
ATTACK — Attempts to destroy or weaken an existing node. Steelman, defeat condition, adversarial test. Primary death risk: incomplete branch generation (missed alternatives).
BRIDGE — Connects nodes from different domains. Cross-domain isomorphism. Primary death risk: metaphor masquerading as structure.
ANCHOR — Roots an abstract node in physical reality. Evidence, experiment, measurement. Primary death risk: empirical contradiction or theory-evidence gap.
DECLARE — Marks a node's epistemic status as settled. Classification, worldview elimination, conclusion. Primary death risk: premature closure without full propagation test.

### Layer 3 — THE SPINE (five fields, every operation, every domain)

OPERATION: Which of the six?
TARGET: Which existing nodes does this operate on? Name them specifically.
RESULT: What does this operation produce? One clear sentence.
VULNERABILITY: Which death condition is this result most exposed to?
UNLOCKS: What becomes possible in the knowledge graph because of this result?

---

## THE ADDITIONAL LEGS (structural rigor beyond the spine)

These questions add legs to the table. One leg is unstable. Twenty legs is bedrock.

CONVERGENCE: How many independent paths from different domains arrive at the same claim? List them. (Physics → claim. Theology → claim. Information theory → claim. Each independent path is one leg.)

LOAD-BEARING: What currently-standing claims in the framework depend on this node? If this node falls, what falls with it? This is the cascade analysis — not what this unlocks forward, but what stands on it now.

HONEST BLANK: What does the document NOT resolve? What acknowledged gap remains? Not the external attack (that's VULNERABILITY) — the internal admission. What would the author say they haven't fully worked out?

WORLDVIEW PRESSURE: Which worldviews does this claim put direct pressure on, and at which specific point? Be precise. "Materialism" is not precise enough. "Materialism fails here because it cannot define its own primitive without recourse to informational properties" is precise.

CROSS-DOMAIN STRUCTURAL CHECK (required if operation = BRIDGE, optional otherwise):
  - Are the connected entities structurally isomorphic, or merely analogous in language?
  - Does the isomorphism constrain predictions in BOTH domains, or only one?
  - Can the bridge be falsified independently in each domain?
  - If the isomorphism is only one-directional, classify it as METAPHOR, not BRIDGE.
